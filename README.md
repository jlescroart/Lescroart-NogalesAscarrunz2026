# Lescroart-NogalesAscarrunz2026
Archived code for analyses in Lescroart, Nogales-Ascarrunz et al. (2026).

Code (in progress) for analysis of historic and modern sequencing data of tiger cats.

## Data access:
Raw WGS reads generated for this study can be found on SRA under BioProject accession number [PRJNA1176476](https://www.ncbi.nlm.nih.gov/bioproject/?term=PRJNA1176476).	Intermediate data consisting of 100-kb fragmented genomic Multiple Sequence Alignments (MSA) and derived set of 22,873 locally inferred trees can be accessed on figshare: [MSA](https://doi.org/10.6084/m9.figshare.31444240) and [local tree set](https://doi.org/10.6084/m9.figshare.31446004).
